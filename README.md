# Devesh Kumar Singh

Personal site and technical blog for [deveshkumarsingh.com](https://deveshkumarsingh.com).

## Write a post

1. Copy `content/posts/_template.mdx`.
2. Rename it to `your-slug.mdx`.
3. Fill frontmatter: `title`, `description`, `date`, `category`, `tags`, optional `faq`.
4. Set `draft: false` or remove it.
5. Write in Markdown. The first paragraph is the answer engines will quote.

Categories: `react-native`, `ai`, `backend`, `esg`, `sustainability`, `contextual-intelligence`.

## Run locally

```bash
npm install
npm run dev
```

## SEO surfaces

- `/sitemap.xml`
- `/robots.txt`
- `/feed.xml`
- `/llms.txt`

After deploy, add the domain in Google Search Console and submit the sitemap. Point `deveshkumarsingh.com` DNS to this host.
